# GameSnap：游戏内一键全屏截图

在游戏里按一下 **`** 键（Esc 下面、数字 1 左边那个键）就能截下整个屏幕：
- 不用框选；
- 游戏不会切回桌面；
- 截图自动按游戏分文件夹保存，同时复制到剪贴板。

## 使用

1. 双击桌面上的「米哈游启动器 + 截图」快捷方式，在 UAC 提示里点「是」。米哈游启动器和 GameSnap 会一起打开。
   - 原神是以管理员身份运行的，GameSnap 也必须有管理员权限，才能在游戏里收到按键。
   - 启动器（`HYP.exe`）本身也要管理员权限。它由已经提权的 GameSnap 拉起，所以进游戏时不会再弹第二次 UAC。
   - 这个快捷方式勾了「以管理员身份运行」（属性 → 快捷方式 → 高级），双击后马上弹 UAC，GameSnap 一启动就有权限。UAC 里点「否」则什么都不启动。
   - 没勾也能用：GameSnap 会先以普通权限启动，再自己申请权限，只是多启动一遍，慢约 0.2 秒。重建这个快捷方式时记得勾上。
2. 任务栏右下角会出现托盘图标：灰色表示等待进游戏，绿色表示工作中，橙色表示暂停。
3. 进游戏后按 `，右上角会弹出「✓ 已截图 · 原神」，大约 1 秒后消失。
4. 游戏和启动器都关掉约 10 秒后，GameSnap 也会自己退出，不常驻后台。

玩云·原神时用桌面上的「云·原神 + 截图」，用法一样。云·原神客户端以普通权限运行，所以这个快捷方式带了 `--no-elevate`，也没勾「以管理员身份运行」，不会弹 UAC。

玩 Switch 游戏（yuzu 模拟器）时用「yuzu + 截图」，用法也一样。yuzu 同样以普通权限运行，这个快捷方式也带了 `--no-elevate`，不会弹 UAC。yuzu 开着就算在玩，停在游戏列表时按 ` 也会截图。

开始菜单里也有这三个快捷方式，和桌面上的一样。

这几个快捷方式可以同时用，同一时间只会有一个 GameSnap，开着的游戏它都管：
- 先开云·原神或 yuzu、后开米哈游启动器：管理员权限的 GameSnap 接替原来那个，原神里按键才有效；云·原神、yuzu 照样能截。
- 先开米哈游启动器、后开云·原神或 yuzu：已经在运行的 GameSnap 都管，不会再起第二个。
- 关掉其中一个、接着玩另一个，GameSnap 不会退出。米哈游启动器和名单里的游戏（原神、云·原神、yuzu 等）全部关掉后，再等 10 秒才退出。都关掉以后再玩，用带「+ 截图」的快捷方式打开，GameSnap 会跟着启动。

不用快捷方式也可以：直接双击 `dist\GameSnap\GameSnap.exe`，退出规则一样。

想截 Steam、微软商店等别的游戏，见「加别的游戏」。

快捷方式实际执行的命令：

```
dist\GameSnap\GameSnap.exe --launch "D:\miHoYo Launcher\launcher.exe"
```

想要「原神 + 截图」这种直接进某个游戏的快捷方式，加上 `--launch-args "--game=hk4e_cn"` 即可（星铁是 `hkrpg_cn`，绝区零是 `nap_cn`）。

截图保存在 `图片\GameShots\<游戏名>\`，例如 `GameShots\原神\原神_2026-10-11_21-30-05.png`。

yuzu 里的截图按正在玩的 Switch 游戏分文件夹。游戏名取自 yuzu 的窗口标题，和 yuzu 里显示的一样，例如 `GameShots\塞尔达传说 王国之泪\`；停在游戏列表时存到 `GameShots\yuzu\`。文件名里不能用的字符（如 `:`、控制字符）会换成 `_`；游戏名超过 80 个字符时截断；`CON`、`NUL` 这类 Windows 保留名前面加 `_`；只有点（如 `..`）的名字存到 `GameShots\未知游戏\`；结尾连续多个点和空格（如 `Loading...`）的去掉，结尾单个点不动。

## 加别的游戏

Steam、微软商店或其他平台的游戏都能自己加进名单，不用改代码，也不用手改配置：

1. 先打开游戏，再打开 GameSnap（双击 `dist\GameSnap\GameSnap.exe`，或者用哪个「+ 截图」快捷方式都行）。
2. 右键托盘图标 →「添加游戏…」，然后在 15 秒内切到游戏画面里按一下 `。
3. 弹出「✓ 已添加 · 游戏名（进程名.exe）」就加好了，马上生效，不用重启 GameSnap。之后在这个游戏里按 ` 就是截图，存在 `GameShots\<游戏名>\`。

- 添加时按的这一下只用来添加，不截图。等待的 15 秒里，在任何窗口按 ` 都算「添加」，不会打出字来。
- 游戏名取自窗口标题，去掉「 - 」「 | 」「 (」后面的版本号之类；没有标题或标题太长时用进程名。想改名，改 config.json 里 `games` 的对应项（见「配置」）。
- 在不是游戏的程序里按（桌面、浏览器、微信 / QQ、Claude 等 AI 应用、代码编辑器、Office、Steam 客户端、启动器等），会提示「这不是游戏窗口」，接着等你到游戏里再按。15 秒内没按就提示「没有添加游戏」，什么都不改。
- 哪些程序算「不是游戏」，列在 `not_games.py` 里：常用软件，加上这台电脑上装的非游戏软件（2026-10-31 按开始菜单、桌面快捷方式和已安装程序整理）。没列到的程序照样能加进去，以后新装的软件也一样。改了这个文件要重新打包才生效。万一哪个游戏被误拦，可以手加到 config.json 的 `games` 里，手加不受这个名单限制。
- 加错了，右键托盘图标 →「游戏名单」，点那一项，确认后就移除了，马上生效。
- 游戏启动时弹 UAC 的，说明它以管理员身份运行，GameSnap 也要有管理员权限才收得到按键：双击 `dist\GameSnap\GameSnap.exe`，在 UAC 里点「是」。「云·原神 + 截图」「yuzu + 截图」打开的 GameSnap 没有管理员权限，在这种游戏里按键没反应，15 秒后提示没有添加。
- 加不了的情况：老式的商店应用，窗口不归游戏进程管，会提示「这不是游戏窗口（ApplicationFrameHost.exe）」，现在商店里的 PC 游戏大多不是这种。另外，个别游戏禁止截屏，截出来是黑的，GameSnap 也没办法。

### 给新游戏建「+ 截图」快捷方式（可选）

GameSnap 不常驻，玩之前得把它打开。嫌每次手动开麻烦，就建一个快捷方式让两者一起启动：桌面右键 → 新建 → 快捷方式，「对象的位置」填下面对应的一行。

- Steam 游戏：`<AppID>` 是游戏的 Steam 商店页地址里的那串数字（`store.steampowered.com/app/<AppID>/`）。
  ```
  "D:\0_my_projects\anthropic_claude_code\game_snap\dist\GameSnap\GameSnap.exe" --no-elevate --launch "steam://rungameid/<AppID>"
  ```
- 微软商店 / Xbox 游戏：`<AppID>` 在 PowerShell 里运行 `Get-StartApps` 查，找到游戏那一行的 AppID 列。
  ```
  "D:\0_my_projects\anthropic_claude_code\game_snap\dist\GameSnap\GameSnap.exe" --no-elevate --launch explorer.exe --launch-args "shell:AppsFolder\<AppID>"
  ```
- 其他游戏：直接写游戏的 exe。
  ```
  "D:\0_my_projects\anthropic_claude_code\game_snap\dist\GameSnap\GameSnap.exe" --no-elevate --launch "D:\Games\某游戏\Game.exe"
  ```

`--no-elevate` 表示不要管理员权限，不弹 UAC；Steam 没开着时，也不会让 Steam 以管理员身份启动。游戏本身要管理员权限（启动时弹 UAC）的，去掉 `--no-elevate`，再在快捷方式属性 → 快捷方式 → 高级里勾上「以管理员身份运行」。

用快捷方式打开后，游戏要在 60 秒内启动，否则 GameSnap 会先退出（比如 Steam 正在更新）。这时等游戏开起来，再双击 `GameSnap.exe` 就行。

## 工作方式

- **随游戏启停**：每 2 秒看一次进程列表，名单里的游戏在运行时才挂上按键监听。自动退出的规则：
  - 启动器（`HYP.exe`）开着就一直等：下载大版本更新时间再长、游戏关了待会儿还要再进，都不会提前退出；
  - 玩过游戏后，名单里的游戏（包括云·原神客户端和 yuzu）和启动器全部关掉，再等 10 秒才退出，只关掉其中一个不会退出；
  - 刚启动时如果既没有游戏也没有启动器，等 60 秒后退出。
  - 到了该退出的时候托盘菜单正开着，也照样退出：最多多等 3 秒，菜单跟着消失，日志里多一行说明。
  - 如果你习惯把启动器留在托盘里，GameSnap 也会一直在。这时它只占约 1.4MB 内存，CPU 几乎为 0。
- **只在游戏窗口里拦截 `**：切到微信、浏览器、代码编辑器时，` 照常能打出来（「添加游戏…」等你按键的那 15 秒除外）。
- **按下即抓**：截到的是按键后第一次上屏的那一帧，实测比按键晚 7–13ms，不超过 2 帧。刚从别的窗口切回游戏就按，也只晚约 25ms。每张 PNG 的元数据里都记录了这个时间差，日志里也有。
- **提示浮层**：不抢焦点，鼠标点击会穿透，也不会出现在下一张截图里。
- **截图方式**：Windows Graphics Capture，D3D 设备只建在驱动这块显示器的显卡上（这台笔记本是 AMD 核显）。画面本来就由它合成，不用跨显卡搬运，也不占 NVIDIA 独显的显存。这条路不行时自动改用 GDI。
- **截图会话开了就不关**：游戏第一次切到前台时打开，之后切走、游戏退出都不关；GameSnap 退出时也不做清理，直接结束进程。关会话后 Windows 内部延迟执行的清理偶尔会让 GameSnap 崩溃（崩了之后再进游戏就截不了图），所以不关。会话开着几乎不耗资源，只多占帧池里两帧画面的显存（1080p 约 16MB）。
- **不碰游戏进程**：不读写游戏内存，不注入任何东西，连进程句柄都不打开。

## DualSense 手柄震动

PS5 手柄（DualSense）用 USB 连接玩原神时，手柄的声音设备要设成「四声道」，并勾选两项「全音域扬声器」（左前和右前、环绕），震动才有效。Windows 按 USB 口认这只手柄，换个口就当成新的声音设备，设置回到默认。所以 GameSnap 运行期间替你看着：

- **什么时候查**：GameSnap 启动时查一次；之后手柄插拔、声音设置有变化时再查（用注册表变化通知，平时不占 CPU）。
- **不对就改**：改成四声道、前后全音域，改完重新读一遍核对。改了会弹提示；游戏已经开着的话，没有震动就重启一下游戏。
- **改不成**：每次插入最多试 3 次，还不行就提示「没能改成四声道，详见日志」。
- **只认 DualSense**：看硬件编号（DualSense 是 054C:0CE6，DualSense Edge 是 054C:0DF2），不看设备名。只改扬声器配置这一项，不碰默认设备、音量等其他设置。
- 设置本来就对时不提示，只在日志里记一行。

改设置用的是 NirSoft 的免费工具 [SoundVolumeCommandLine](https://www.nirsoft.net/utils/sound_volume_command_line.html)（`svcl.exe` v1.28）。Windows 没有公开的修改扬声器配置的接口，声音设置面板用的是系统内部接口，svcl 把它包好了。它放在 `tools\svcl\`（压缩包里的三个文件原样放着），打包时一起放进 `dist`。没有它时 GameSnap 只提醒、不自动改。要更新它：从上面的页面下载 `svcl-x64.zip`，用里面的文件覆盖 `tools\svcl\`，再重新打包。

- 关掉这个功能：托盘菜单取消勾选「DualSense 自动四声道」。
- 把手柄改回去：声音设置 → 更多声音设置 → 播放 → 选中 DualSense 的扬声器 → 配置 → 立体声。

## 资源占用（实测）

「专用工作集」就是任务管理器「内存」列显示的值。

| 状态 | 专用工作集 | 工作集 | CPU |
|---|---|---|---|
| 不玩游戏 | 0（进程已退出） | 0 | 0 |
| 等待进游戏 | 约 1.4MB | 约 2MB | 几乎为 0 |
| 游戏运行中（待命） | 约 20MB | 约 46MB | 几乎为 0 |
| 截过图之后 | 约 29MB | 约 56MB | 只在按键时用一下 |

几点说明：
- 等待进游戏时，每分钟把闲置内存交还系统一次，所以物理内存只占 1–2MB。游戏中不这么做，保证按键响应及时。
- 进程检测平时只读进程 ID 列表，每次约 0.05ms；有新进程出现时才读一次进程名。
- 截过图之后多出的约 8MB，是从显卡读回画面用的缓冲区，留着下次直接用。
- 启动约 0.3 秒，只有一个进程，不往 `%TEMP%` 解压任何东西。

## 配置

配置文件在 `%APPDATA%\GameSnap\config.json`（第一次运行时生成）。手改时先退出 GameSnap（托盘菜单 → 退出），改完再打开。GameSnap 开着时改的话，它下次保存设置（切换菜单开关、添加或移除游戏）会把你改的覆盖掉。

手改出错、文件读不出来（比如多了个逗号）时，GameSnap 用默认配置启动，并先把读不出来的那份另存为同一文件夹里的 `config.unreadable_<日期_时间>.json`，日志里也会记一笔。之后它保存设置时 `config.json` 会变回默认配置；把另存的那份改好，再改名回 `config.json`（先退出 GameSnap）即可找回原来的游戏名单和截图键。

文件读得出来、但某一项的值不对时（比如 `poll_interval_sec` 写成 0 或 `null`、`games` 写成 `null`、开关写成 `"yes"`），只有那一项用默认值，其他项照常生效；`games` / `launchers` 里个别项不对时只去掉那几项。这种情况同样先把原文件另存为 `config.invalid_<日期_时间>.json`，日志里写明是哪一项、为什么。秒数的下限：`poll_interval_sec` 不小于 0.1，`exit_grace_sec`、`wait_no_launcher_sec` 不小于 0。

保存设置时 config.json 被别的程序（杀毒软件、同步盘）短暂占着，GameSnap 会重试约 1 秒；仍保存不上就提示「设置没保存上（config.json 被占用），详见日志」。这次改的设置照样生效，等下次保存设置时再写进文件。

启动时 config.json 被占着，同样重试约 1 秒。仍读不出来、也没能另存一份时，GameSnap 弹窗提醒，这次用默认配置运行（游戏名单也是默认的），设置不写回文件，原来的 config.json 不会被改动；退出后等占着它的程序结束，再打开就恢复了。

- `games`：游戏名单，`{"进程名.exe": "文件夹名"}`。默认包含原神、云原神、星穹铁道、绝区零、崩坏3、yuzu（Switch 模拟器）。用托盘菜单「添加游戏…」加、「游戏名单」移除最方便（见「加别的游戏」）；手加的话，进程名可在任务管理器的「详细信息」页里查到。
- `save_dir`：截图根目录。留空就是 `图片\GameShots`。
- `hotkey`：截图键。建议用托盘菜单改，不要手改。
- `launchers`：启动器进程名，默认 `["HYP.exe"]`。
- `exit_grace_sec` / `wait_no_launcher_sec`：上面自动退出规则里的 10 秒和 60 秒。
- `dualsense_quad`：DualSense 自动四声道，默认 `true`，和托盘菜单里的开关是同一个。

日志在 `%APPDATA%\GameSnap\gamesnap.log`，超过 1 MB 时旧内容挪到 `gamesnap.log.1`。别的程序或另一个 GameSnap 正开着它时挪不动，就接着往原文件写，之后再挪。日志被别的程序禁写时，这次不写日志，GameSnap 照常运行。截出黑屏或感觉有延迟时，可以先看这里。提示「按键监听没启动起来，截图键暂时无效」时，截图键、更换截图键、添加游戏都暂时用不了，原因记在日志里；之后检测到游戏、或点「更换截图键…」「添加游戏…」时会重试。

GameSnap 如果突然消失（日志最后没有「退出」那一行），说明崩溃了。崩溃时各线程执行到哪一行会记在同一个文件夹的 `crash.log` 里，发给我即可。这个文件每次启动只会多一行时间戳。

## 从源码运行 / 打包

本项目的依赖只装在专用的 conda 环境 `gamesnap-build` 里，不装进 `py312-clean`。这个环境是 Python 3.12，依赖按 `requirements.txt` 用 pip 装：

```
D:\anaconda3\envs\gamesnap-build\python.exe main.py         # 从源码运行，会请求管理员权限
D:\anaconda3\envs\gamesnap-build\python.exe build.py        # 生成 dist\GameSnap\ 文件夹
D:\anaconda3\envs\gamesnap-build\python.exe -X utf8 tests\run_tests.py   # 跑测试，加 all 跑完整的（见 tests\README.md）
```

打包时会把 `tools\svcl\` 一起放进去（见「DualSense 手柄震动」）。没有 `tools\svcl\svcl.exe` 时 build.py 会给出警告，打出来的版本只提醒、不自动改。

打包成文件夹版（约 40MB、92 个文件），不打成单个 exe。单文件版每次启动都要先往 `%TEMP%` 解压约 64MB，多花约 1 秒，还多一个进程；被强制结束时，解压目录还会残留。

命令行参数：
- `--launch 程序或链接`：同时启动这个程序，也可以是 `steam://rungameid/…` 这类链接；`--launch-args 参数`：传给它的参数；
- `--no-elevate`：不请求管理员权限；
- `--console`：日志同时打印到控制台；
- `--config 路径`：使用指定的配置文件。

## 旧版备份

`backup\v1_onefile_dxcam\` 里是改版前的单文件 `GameSnap.exe` 和源码。那一版用 dxcam 截图，游戏中约占 105MB。要退回旧版，把七个快捷方式（桌面和开始菜单里各三个，开始菜单另有一个 `GameSnap.lnk`）的目标都改成那里的 `GameSnap.exe` 即可。

`backup\v2_wgc_close_session\` 里是 2026-10-29 修复前的文件夹版（`GameSnap\GameSnap.exe`）和源码。那一版游戏切走或退出时会关闭截图会话，偶尔因此崩溃。要退回这一版，把七个快捷方式的目标都改成那里的 `GameSnap\GameSnap.exe` 即可。

`backup\v3_wgc_keep_session\` 里是 2026-10-30 加 DualSense 功能之前的文件夹版（`GameSnap\GameSnap.exe`）和源码。要退回这一版，同样把七个快捷方式的目标都改成那里的 `GameSnap\GameSnap.exe`。只是不想要 DualSense 功能的话，不用退回，在托盘菜单里关掉即可。

`backup\v4_dualsense\` 里是 2026-10-31 加 yuzu 之前的文件夹版（`GameSnap\GameSnap.exe`）和源码。退回这一版后 yuzu 照样能截（yuzu 写在 config.json 的游戏名单里），只是截图都放进 `GameShots\yuzu\`，不按游戏分。

`backup\shortcuts_before_runas\` 里是 2026-10-31 勾「以管理员身份运行」之前的两个「米哈游启动器 + 截图」快捷方式（桌面、开始菜单各一个）。想改回去，在快捷方式属性里取消勾选即可。

`backup\before_yuzu\config.json` 是加 yuzu 之前的配置文件。

`backup\before_remove_claude\config.json` 是 2026-10-31 从游戏名单里删掉误加的 Claude 之前的配置文件。

## 卸载

删掉以下四样即可：
- 桌面上的「米哈游启动器 + 截图」「云·原神 + 截图」「yuzu + 截图」快捷方式；
- 开始菜单里同名的三个快捷方式（文件在 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\`）；
- 本项目文件夹；
- `%APPDATA%\GameSnap` 文件夹。

程序自己不写注册表，也不装服务。DualSense 的扬声器配置是 Windows 的设置，卸载后仍是四声道；想改回去见「DualSense 手柄震动」。
